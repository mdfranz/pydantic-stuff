## Decision-Model Assessment

- **Decision Quality & Determinism** `[Primary]`: Top-performing open System One decision family on Jev Decision Index 0.3.2 across all size tiers (`d3:2b` `38.9`, `d3:4b` `52.6`, `d3:9b` `55.8`, `d3:27b` `66.3` — every variant sits on the official Pareto frontier). Notably, `d3` includes **still-image vision support across all sizes (`2b`, `4b`, `9b`, `27b`)** on Ollama, whereas `autotrust-jev:9b` on Ollama is Text-only.
- **Structured Output & JSON Schema** `[Primary]`: Native `/v1/systemone` endpoint returns calibrated `choice`, `noul` (yes/no), and `score` JSON answers with probabilities and confidence. Does not generate free-form text or arbitrary JSON strings.
- **Tool & Function Calling** `[Primary]`: `/v1/systemone` does not execute or generate tool calls directly; within `pydantic-ai`, `DecisionModel` uses `d3` to pick which route/tool applies and escalates via `ModelFallback` when free-form tool arguments are needed.
- **Thinking / Latency Tradeoff** `[Primary]`: Zero thinking-token generation (`output_tokens: 0`); answers multiple questions in one request (`each from its own forward pass over the input`).
- **Quantization & Context Notes** `[Primary]`:
  - **Context cap**: Ollama's `d3` packages use a **4,096-token context** (vs. 256K in model tags).
  - **Quantization caveat**: Published Jev Decision Index 0.3.2 scores are from the **unquantized (`bf16`) Hugging Face checkpoints**, NOT the Ollama `MXFP8`/`NVFP4`/`Q8_0` packages `[Primary]`.
  - **Modality caveat**: HF `vllm-sr/d3*` supports text, JSON, images, **and video** (`77.4` Perception Test on 27B, `73.3` on 9B), and 255 answer codes; on Ollama, **video and Box/Track decisions are unavailable**, and `/v1/systemone` limits local choice to 26 options and score to 10 levels.
- **Operational & pydantic-ai Readiness** `[Primary]`: **`Out-of-the-box`** (`Minor config` recommended) via `pydantic-ai`'s `SystemOneModel` (`'system-one:d3:9b-nvfp4'` or `'system-one:d3:4b'`) and `SystemOneProvider(base_url='http://localhost:11434')` (no `/v1` suffix).
  - **Profile config**: Set `DecisionModelProfile(decision_max_choice_options=26, decision_max_score_levels=10)` to match Ollama's local `/v1/systemone` limits, and set `context_window=4096` to match Ollama's `d3` package limit.
  - **Possible DIY gap (vision)**: Verify locally whether `pydantic-ai`'s `SystemOneModel` currently maps `BinaryContent` image inputs to Ollama's `/v1/systemone` `"images": [...]` payload; if not, wrap `SystemOneModel` or call `/v1/systemone` directly for multimodal image decisions.

## Caveats & Open Questions

- **Requires Ollama v0.40.9+**: Older Ollama builds (such as v0.35.x) will not run `d3` `[Primary]`.
- **4,096-Token Context Package Limit**: Ollama's `d3` builds use a 4k context window despite 256K appearing in tag metadata `[Primary]`.
- **Quantization Drift Unmeasured**: Official Jev Decision Index scores are `bf16` only; local accuracy/calibration differences between `MXFP8`, `NVFP4`, and `Q8_0` on M4 are `TBD`.
- **27B on 24GB M4**: Only `d3:27b-nvfp4` (`17 GB`) fits under 24GB on paper, leaving tight OS headroom (~17.5–18.5 GB loaded `[Estimated]`); `d3:9b-nvfp4` / `9b-mxfp8` and `d3:4b-mxfp8` are much safer daily drivers.
- **No Video on Ollama**: Video decision support in `vllm-sr/d3` is unavailable in Ollama's `d3` runtime `[Primary]`.
