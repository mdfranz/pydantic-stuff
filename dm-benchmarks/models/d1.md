## Decision-Model Assessment

- **Decision Quality & Determinism** `[Primary]`: Purpose-built System One multimodal decision model scoring all options of all questions in one forward pass (`noul`, `choice`, `score`). `d1-2B` outperforms the older `d1-3B` across Decision Index v0.3 public (`51.1` vs `49.0`), JevBench v1.4.1 (`77.9` vs `76.2`), and ImajevBench v2.0-lite (`75.5` vs `64.0`) with under two-thirds of the parameters. Supports **16 languages** (AR, ZH, EN, FR, DE, HI, ID, IT, JA, KO, PL, PT, RU, ES, TH, VI).
- **Structured Output & JSON Schema** `[Primary]`: Native `/v1/systemone` endpoint returns typed `choice`, `noul` probability, and `score` outputs with `confidence`. Does not generate free-form text or arbitrary JSON strings.
- **Tool & Function Calling** `[Primary]`: `/v1/systemone` does not support tool execution directly; in `pydantic-ai`, `DecisionModel` uses `d1` for route/tool selection and escalates via `ModelFallback` when free-form tool arguments are needed.
- **Thinking / Latency Tradeoff** `[Primary]`: Zero output tokens generated; single forward pass.
- **Quantization & Context Notes** `[Primary]`: `d1:2b` offers `125K` context and `MLX` `NVFP4`/`MXFP8`/`BF16` weights (`3.9 GB` BF16 fits comfortably on 24GB M4 with zero quantization loss). Note that `d1-2B` HF card also mentions video, whereas Ollama `/v1/systemone` supports text, JSON state, and still images (no video).
- **Operational & pydantic-ai Readiness** `[Primary]`: **`Out-of-the-box`** via `SystemOneModel` (`'system-one:d1:2b-mxfp8'` or `'system-one:d1:2b-mlx-bf16'`) + `SystemOneProvider(base_url='http://localhost:11434')` + `DecisionModelProfile(decision_max_choice_options=26, decision_max_score_levels=10)`. Verify locally whether `pydantic-ai`'s `SystemOneModel` forwards `BinaryContent` images to Ollama's `/v1/systemone` `images` field.

## Caveats & Open Questions

- **License Threshold ($10M Revenue Cap)**: `LFM Open License v1.0` prohibits commercial use by legal entities with ≥ $10M annual revenue without a separate license.
- **`latest` Tag Alias**: `ollama pull d1` / `d1:latest` pulls `d1:3b` (`3.7 GB`, 32K ctx, older LFM2.5-VL-3B), not the newer, stronger `d1:2b` (`125K` ctx, LFM3-VL-2B).
- **No Local M4 Measurements Yet**: Base M4 single-pass latency and `NVFP4`/`MXFP8` vs. `MLX-BF16` agreement are `TBD`.
