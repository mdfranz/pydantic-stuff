## Caveats (added after the run)

- **Silent truncation on `laya:latest`**: 56/231 base items report exactly `input_tokens = 512` (= its resident context length) with no error, while other models see up to ~4,100 tokens on the same items. Ollama's docs say decision input is never truncated; every other model errors cleanly on overflow (e.g. `strands-decider`: "decision input exceeds the 4096-token context"). Treat `laya`'s long-item results as truncated-input results. `[Measured]`
- **Option limits are per model**: `laya`, `d1`, `nimble-v3` reject >26 options (`criteria must contain 2–26 candidates`); `strands-decider` is bounded by its 4096-token context (fails at N=255); `d3:4b`, `d3:9b`, `kev` accept 255. `[Measured]`
- **Read rule**: `Acc` uses argmax. pydantic-ai's built-in `SystemOneModel` rounds the expected score for rubrics; see the "Score acc argmax / pai-round" column. `[Measured]`
- Single run, quantized weights, M4 base; not comparable to the official JevBench board.
